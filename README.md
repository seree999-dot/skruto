# ระบบขออนุมัติเดินทางไปราชการ (Official Travel Request System)

ระบบบริหารจัดการการขออนุมัติเดินทางไปปฏิบัติราชการสำหรับหน่วยงานภาครัฐและองค์กร พัฒนาด้วยเทคโนโลยี Serverless & Modern Web Application 100% โดยใช้ **Single HTML File** ทำงานร่วมกับ **Google Sheets** ผ่าน **Google Apps Script** และโฮสต์ผ่าน **GitHub Pages**

🔗 **GitHub Repository:** [https://github.com/seree999-dot/skruto](https://github.com/seree999-dot/skruto)  
🌐 **Live Website:** [https://seree999-dot.github.io/skruto/](https://seree999-dot.github.io/skruto/)

---

## 🌟 ฟังก์ชันการทำงาน 5 เมนูหลักที่สำคัญที่สุด + เมนูรายงานผล

1. **ยื่นขออนุมัติเดินทางไปราชการ (New Request Form)**
   * กรอกข้อมูลผู้ขอและผู้ร่วมเดินทาง
   * เลือกประเภทภารกิจ (อบรม/สัมมนา, ประชุม, นิเทศงาน, ภาคสนาม)
   * ระบบคำนวณจำนวนวันเดินทางให้อัตโนมัติ (Start Date - End Date)
   * เลือกรถส่วนกลาง / รถส่วนบุคคล (ขอเบิกค่าน้ำมัน) / ยานพาหนะสาธารณะ
   * ระบบคำนวณประมาณการค่าใช้จ่ายอัตโนมัติ (เบี้ยเลี้ยง, ที่พัก, น้ำมัน, ค่าลงทะเบียน)
   * แนบลิงก์โครงการ/หนังสือเชิญจาก Google Drive
   * สร้างรหัสคำขออัตโนมัติ เช่น `TR-202610-0001`

2. **ตรวจสอบและติดตามสถานะคำขอ (Status Tracking & History)**
   * ค้นหาคำขอด้วยรหัสคำขอ หรือชื่อผู้ขอ
   * แสดงสถานะแบบเรียลไทม์ (รอพิจารณา / อนุมัติแล้ว / ไม่อนุมัติ / เสร็จสิ้นภารกิจ)
   * **ระบบพิมพ์แบบฟอร์มบันทึกข้อความขออนุมัติราชการ:** ฟอร์มมาตรฐานพร้อมตราครุฑ จัดหน้าสำหรับสั่งพิมพ์ (Print) หรือบันทึกเป็นไฟล์ PDF ได้ทันที

3. **ระบบพิจารณาอนุมัติสำหรับผู้บริหาร (Executive Approval Portal)**
   * ระบบความปลอดภัยด้วยรหัส PIN ผู้อนุมัติ (Default PIN: `1234`)
   * ตรวจสอบคำขอที่ค้างพิจารณา พร้อม Badge แจ้งเตือน
   * ปุ่มอนุมัติ หรือ ไม่อนุมัติ/ส่งกลับแก้ไข พร้อมบันทึกข้อสั่งการและความเห็น

4. **ปฏิทินและตารางการใช้รถราชการ (Travel & Fleet Calendar)**
   * แสดงตารางปฏิทินการเดินทางประจำเดือนของทั้งหน่วยงาน
   * ตารางตรวจสอบการจองรถยนต์ส่วนกลาง ป้องกันการขอใช้รถซ้อนทับกัน

5. **บันทึกรายงานผลหลังเดินทางไปราชการ (Post-Travel Reporting)**
   * ดึงข้อมูลคำขอที่ได้รับการอนุมัติแล้วมาทำรายงาน
   * สรุปสาระสำคัญของภารกิจ และประโยชน์ต่อหน่วยงาน
   * สรุปค่าใช้จ่ายจริงที่เบิกจ่าย
   * แนบลิงก์รูปภาพกิจกรรม / เอกสารเบิกจ่าย และอัปเดตสถานะเป็น "เสร็จสิ้นภารกิจ"

6. **เมนูพิเศษ: แดชบอร์ดสถิติและรายงานผล (Analytics Dashboard)**
   * การ์ดสรุปตัวเลขสถิติ (KPIs)
   * กราฟ Chart.js วิเคราะห์รายกลุ่มงาน/ฝ่าย และสัดส่วนประเภทภารกิจ
   * ตารางสรุปข้อมูลพร้อมปุ่มส่งออกเป็น **Excel / CSV** และปุ่มพิมพ์รายงาน

## 🚀 ขั้นตอนการติดตั้งและตั้งค่าระบบ (Step-by-Step Installation)

### ขั้นตอนที่ 1: เตรียม Google Sheet ฐานข้อมูล
1. เข้าไปที่ [Google Sheets](https://sheets.new) แล้วสร้างสเปรดชีตใหม่ ตั้งชื่อว่า **"ฐานข้อมูลระบบขอไปราชการ"**
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**

### ขั้นตอนที่ 2: ติดตั้งโค้ดใน Google Apps Script
1. ลบโค้ดเดิมใน Apps Script ออกทั้งหมด
2. คัดลอกโค้ดจากไฟล์ `Code.gs` ในโครงการนี้ไปวาง
3. ในแถบเครื่องมือด้านบน เลือกฟังก์ชัน `setupInitialData` แล้วกดปุ่ม **เรียกใช้ (Run)** 1 ครั้ง
   * *(ระบบจะสร้างชีต `Requests`, `TravelReports` และ `SystemConfig` พร้อมตั้งหัวตารางให้อัตโนมัติ)*
4. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy) > รายการทำให้ใช้งานได้ใหม่ (New deployment)**
   * **เลือกประเภท:** เว็บแอป (Web app)
   * **คำอธิบาย:** ระบบขอไปราชการ v1.0
   * **ดำเนินการในนามของ:** ฉัน (Me)
   * **ผู้ที่มีสิทธิ์เข้าถึง:** **ทุกคน (Anyone)** *(สำคัญมาก ต้องเลือก Anyone เพื่อให้เว็บหน้าบ้านส่งข้อมูลได้)*
5. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web app URL)** ที่ลงท้ายด้วย `/exec`

### ขั้นตอนที่ 3: เชื่อมต่อ Web App URL กับหน้าเว็บ
1. เปิดหน้าเว็บ `index.html` บนเบราว์เซอร์
2. คลิกปุ่ม **"เชื่อมต่อ Google Sheet"** ที่มุมบนขวา
3. นำ URL เว็บแอปที่คัดลอกมาวางในช่อง แล้วกด **"บันทึกการเชื่อมต่อ"**
4. ระบบจะทำการบันทึกและเชื่อมต่อกับ Google Sheet ของท่านทันที

## 🌐 การ Deploy ผ่าน GitHub Pages

หากต้องการเปิดใช้งานผ่าน GitHub Pages:
1. เข้าไปที่คลัง [https://github.com/seree999-dot/skruto](https://github.com/seree999-dot/skruto)
2. ไปที่แท็บ **Settings** > เมนูด้านซ้ายเลือก **Pages**
3. ภายใต้หัวข้อ **Build and deployment**:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` / Folder: `/(root)`
4. กด **Save**
5. รอ 1-2 นาที ท่านสามารถเข้าใช้งานระบบได้ที่:  
   👉 `https://seree999-dot.github.io/skruto/`
